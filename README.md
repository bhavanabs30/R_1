# RAB Tech Academy Internship – Task 02

## Service Blueprint, SLOs & Cloud Cost Envelope

This project designs the operational plan for a small two-tier web service before deployment.

It includes:

- Service blueprint showing request, dependency, data, deployment, and failure paths
- SLIs, SLO targets, error budgets, and paging thresholds
- Cloud-cost estimates for low, medium, and high traffic scenarios
- Cost chart covering compute, storage, transfer, logging, backup, and support
- Architecture Decision Records for region, recovery objectives, secrets, and least-privilege access

### Tools Used

- Google Colab
- Python
- Pandas
- Matplotlib

### Deliverables

- `service_blueprint.png`
- `slo_workbook.csv`
- `three_scenario_cost_model.csv`
- `cost_envelope_chart.png`
- `architecture_decision_records.md`

> Cloud prices shown in this project are planning estimates and exclude taxes. Final deployment costs should be verified using the official cloud pricing calculator.
